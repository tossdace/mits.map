# MITS Campus Map

A responsive campus information and navigation landing page for Muthoot Institute of Technology & Science.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

The production-ready site is generated in `dist/`. Tailwind CSS is compiled during the Vite build and served as a local stylesheet.
